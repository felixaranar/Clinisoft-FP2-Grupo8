# Descripción del Proyecto #

CliniSoft es un sistema desarrollado en Python para la gestión de pacientes, médicos y citas médicas dentro de una clínica.
El proyecto aplica principios de programación orientada a objetos, incluyendo encapsulamiento, herencia y asociaciones entre clases.
El diseño del modelo se realizó en StarUML, siguiendo las instrucciones y estándares enseñados en clase.

////////////////////

# Funcionalidades Principales #

Registrar pacientes.

Buscar pacientes por ID o nombre.

Listar todos los pacientes.

Registrar médicos.

Programar citas médicas (código, paciente, médico, fecha, hora).

Mostrar métricas generales.

Demostración automática del sistema.
